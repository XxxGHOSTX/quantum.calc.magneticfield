## 🚀 Quick Start

### Option 1: Using pip (Recommended)
```bash
git clone https://github.com/XxxGHOSTX/quantum.calc.magneticfield.git
cd quantum.calc.magneticfield
pip install -r requirements.txt
python web_app.py
```

### Option 2: Using conda
```bash
git clone https://github.com/XxxGHOSTX/quantum.calc.magneticfield.git
cd quantum.calc.magneticfield
conda env create -f environment.yml
conda activate quantum-magnetic-field
python web_app.py
```

### Option 3: Install as Package
```bash
git clone https://github.com/XxxGHOSTX/quantum.calc.magneticfield.git
cd quantum.calc.magneticfield
pip install -e .
python web_app.py
```

**Access**:
- 2D Interface with Infinite Zoom: http://localhost:5000
- 3D Visualization: http://localhost:5000/3d

**Verify Installation**:
```bash
# Run tests
python -m pytest test_x_point.py test_integration.py -v

# Run comprehensive smoke test
python smoke_test.py
```
